# Предыдущие варианты калибровки

Здесь реальные первые изображения, включая неудачные варианты с псевдобуквами и неточными персонажами. Они не являются пятью финальными примерами. round2-файлы показывают следующий промежуточный этап. В раннем generation-log поле max_wait_per_attempt_seconds=15 обозначало интерактивный лимит; для офлайн-генерации отдельно указан offline_render_deadline_seconds=90. Текущий финальный лог различает эти значения явно.
