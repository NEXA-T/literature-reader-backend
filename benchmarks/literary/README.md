Нет независимой экспертной разметки или доверительных интервалов. Валидность

реальный контекст и название книги.

## Источники и воспроизводимость

Цитаты взяты из оригинальных текстов Project Gutenberg. В `source` каждого
теста есть ссылка, глава, номера абзацев и SHA-256 полного скачанного текста.
Нормализованы только пробельные символы внутри абзацев; исходные знаки и
underscore-разметка сохранены. Несколько соседних полных абзацев соединены
пустой строкой без придуманных переходов. Это реальные цитаты, не учебные
ситуации калибровки №10. Показанные английские тексты относятся к историческим
произведениям; условия конкретного электронного издания доступны по ссылке
источника.

Полные книги не коммитятся. Для повторной проверки цитат:

```powershell
python benchmarks/literary/fetch_sources.py
python benchmarks/literary/verify_sources.py
```

Исходные версии SHA-256 зафиксированы в cases.json. Если Project Gutenberg
обновит файл, проверка сообщит о расхождении — нельзя молча считать новый
текст тем же источником. `build_dataset.py` пересобирает набор и дату фиксации;
не запускайте его для изменения корпуса уже проведённого эксперимента.

## Повторный API-прогон

Из корня репозитория, Python с установленными requirements.txt:

```powershell
python benchmarks/literary/run_benchmark.py --env-file "C:\lov3waste\NEXA-T\literature-reader-backend\.env"
```

Новый прогон сохраняется в `results-new.json`, не перезаписывая сдаваемый.
Модель GigaChat-2-Max, temperature=0.1, max_tokens=1400. Время включает работу
метода целиком, в том числе авторизацию и возможные повторы; отдельные
попытки не измерялись. `results.json` хранит возвращённые Pydantic-объекты,
не сырые HTTP-ответы провайдера. API-прогон расходует токены.

Для сборки сдаваемого отчёта из сохранённых результатов и reviews.json:

```powershell
python benchmarks/literary/build_report.py
```

Методика и баллы открыты для пересмотра Данилом/командой. Число 5/15 означает
строгое «все три текстовых критерия получили 2/2», а не отсутствие любой
полезной информации в остальных ответах. Структурно валидны 15/15.

## Генерация картинки

[Тестовая иллюстрация](illustration/scene.jpg) получена встроенным
`text2image` GigaChat из **фактического** поля `image_prompt` теста
`01_tale_tail`, без ручного переписывания описания. Сохранены
[параметры и ответ API](illustration/request-and-result.json): тело запроса,
модель, UUID файла, время, хеш и размер JPG. OAuth-токен и ключ не сохраняются.

```powershell
python benchmarks/literary/generate_scene.py --env-file "C:\lov3waste\NEXA-T\literature-reader-backend\.env" --case-id 01_tale_tail --output-dir benchmarks/literary/illustration-new
```

PoC посылает `function_call=auto`, извлекает UUID только из тега img и делает
GET `/files/{file_id}/content`. Текст ошибки не сохраняется под видом JPEG.
TLS-проверка включена, сертификат берётся из существующих настроек.
Seed, шаги диффузии и выходной размер не задавались: этот интерфейс их здесь
не экспонирует. Иллюстрация скачана из ответа провайдера, а не нарисована
локальной заглушкой.

Визуальная проверка: Алиса и рассказывающая Мышь узнаваемы, надписей нет.
Но добавлены интерьер и стопка книг, которых нет в цитате; хвост пушистый,
похож на беличий. Поэтому это подтверждение работоспособности цепочки
text → image_prompt → image, не гарантированно точная иллюстрация главы.

Выбран встроенный GigaChat, поскольку уже имеется подходящий API-доступ.
Отдельный FusionBrain API не подключался и его работоспособность этим PoC
не подтверждается. [Официальная инструкция](https://developers.sber.ru/docs/ru/gigachat/guides/images-generation).
